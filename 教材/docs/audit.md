## 可恢复检查

在仓库根目录运行 README 中的命令。程序写入 `教材/reports/`，包含检查项目、实际结果和时间；该目录不提交。网站生成 `version.json`，发布时需核对提交号。构建成功不等于视觉检查、来源覆盖或真实学习效果通过。

## 检查限制与发现

- 有限差分检查：平方损失梯度最大绝对误差约 6.33e-10，逻辑回归约 1.07e-10。
- 普通实验运行不输出测试集 MSE；--final 运行已检查。经典模型与 MLP 使用相同生成函数和 360／120／120 划分。
- 首次本机实验因 Matplotlib 默认缓存目录权限产生警告，已将缓存放到本仓库生成目录并重跑通过。
- 手机宽表和长公式允许容器内横向滚动；不强行压缩到不可读字号。桌面和手机抽查不等于逐页逐像素审查，也不等于实体手机实测。
- Markdown 使用显式 HTML 锚点以兼容仓库阅读与网站；不依赖仅自定义生成器理解的标题锚点语法。
- 手机路线图初次显示文字过小，已改为保留字号、容器内横向滑动，并提供等价文字表格；修改后在本地浏览器复查通过。
- 初次线上批量读取第 11 周出现一次 503；完整复查后 46 个 URL 均返回 200。发布检查脚本对暂时错误最多尝试三次，并在报告中保留尝试次数。
- 本页记载已验证的初版作为发布证据。后续提交的确切在线版本以 version.json 和对应 Actions 结果为准；可运行 `check_public.py --expected-commit COMMIT_SHA --external` 重新核对，不能把历史验收当作未来内容已经通过。
