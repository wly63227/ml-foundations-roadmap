# 综合项目：从测量数据到模型比较

## 要解决什么问题

用带噪声的合成测量数据预测连续响应，比较简单线性模型与小型 MLP。工程背景用于帮助理解，不将合成实验解释为真实结构预测或安全结论。

## 固定实验协议

运行 `examples.py evaluation` 与 `examples.py neural`。二者调用同一个数据生成函数：固定种子 42，600 个样本、4 个标准正态特征，响应为 $y=2x_1-x_2+0.7\sin(2x_3)+\epsilon$，其中独立噪声 $\epsilon\sim N(0,0.15^2)$。各 $x_j$ 为无量纲合成特征，不伪造实测单位。

按相同固定索引分为 360 个训练、120 个验证、120 个测试样本；预处理只在训练数据拟合。第 15 周只看训练交叉验证与验证集结果；第 16 周冻结模型方案后再打开测试指标。代码用 `--final` 才输出测试集指标，普通运行不会展示测试结果。

## 第 15 周交付

- 写清问题、特征、响应、合成机制、噪声、固定划分、种子和 MSE 指标。
- 比较训练均值基线、带标准化的 Ridge 和浅决策树。交叉验证必须使用 Pipeline，将预处理留在每个训练折内部。
- 画出预测与残差图，记录验证 MSE、交叉验证均值和标准差。标准差描述当前折结果波动，不声称是置信区间。
- 只在验证集上决定后续候选，保存决定依据；禁止根据测试结果回头选超参数。

## 第 16 周交付

- 用同样划分比较小型 MLP，记录验证曲线、参数、训练轮次与选择理由。
- 按冻结的协议运行 `examples.py evaluation --final` 和 `examples.py neural --final`，一次性报告测试 MSE。
- 如果测试后继续修改模型，明确标为探索；需要新的独立评估设计，不能继续把同一测试集当作未见数据。
- 解释简单模型何时已经足够、神经网络为何可能没有优势，以及结果只对当前合成机制成立。

## 报告模板

1. 问题与假设：数据怎样产生，哪些属于简化。
2. 数据协议：样本数、划分索引、种子、预处理拟合位置。
3. 方法：均值基线、Ridge、浅树、MLP 的配置。
4. 结果：训练交叉验证、验证选择依据、最终测试表，评价指标单位。
5. 误差分析：至少两个具体失败现象及可能原因。
6. 复现：解释器与依赖版本、完整命令、输出文件位置。
7. 局限与下一步：不超出数据支持范围。

## 验收

在新环境按说明可运行；模型使用同一划分与指标；没有预处理泄漏；测试集使用记录清楚；能独立讲解一个梯度推导、一个维度检查和一项失败分析。完成结果记录到 [学习模板](tracker.md)。
