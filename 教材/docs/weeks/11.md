## 问题与直觉

框架怎样替你计算梯度？先用一个能手算的小表达式验证，而不是直接训练大网络。

## 本周知识与阅读

张量 shape 延续 NumPy 维度约定。requires_grad 跟踪计算；backward 累积梯度而非覆盖。张量 .detach 后不再沿原图传播梯度。

[深度学习资源](../resources.md#dl)：D2L 2.1、2.5；可选 PyTorch Tensor、Autograd。

## 手算任务

若 x=(1,2)，f=sum(x²)，求梯度；再对 f=sum((2x+1)²) 求梯度。

先独立完成，再看 [本周参考解](../answers.md#week-11)。参考解为自编，不是教师答案。

## 代码任务

运行 autograd；用双精度张量检查两式。连续 backward 前重新构图，比较清梯度与不清梯度的差别。

在仓库根目录使用已准备好的 Python 环境执行：

```powershell
python 教材/scripts/examples.py autograd
```

如使用 README 的虚拟环境，把 `python` 换成 `.venv/Scripts/python.exe`。安装范围和输出位置见 [环境准备](../setup.md)。跑通示例后遮住核心实现重写，不能只复制运行。
