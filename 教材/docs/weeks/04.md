## 手算任务

把 y=(2,1) 投影到 u=(1,1)；再对 x=[0,1,2]、y=[1,3,5] 写出含截距的 X 和参数。

先独立完成，再看 [本周参考解](../answers.md#week-04)。参考解为自编，不是教师答案。

## 代码任务

运行 linear；用 np.linalg.lstsq 求解，打印 shape、rank 和残差。复制一列制造相关列，观察秩与解的唯一性，而非调用 inv。

在仓库根目录使用已准备好的 Python 环境执行：

```powershell
python 教材/scripts/examples.py linear
```

如使用 README 的虚拟环境，把 `python` 换成 `.venv/Scripts/python.exe`。安装范围和输出位置见 [环境准备](../setup.md)。跑通示例后遮住核心实现重写，不能只复制运行。
