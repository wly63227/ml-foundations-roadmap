# 第 07 周 · 从零线性回归

> 编者组织与自编练习 · 建议 9 小时 · 清单编号：L01、C03、O01、E01。学习状态：未开始。

## 问题与直觉

如何从样本里学出直线，而不是手工猜斜率？从明确损失开始，再比较两种求解方法。

## 本周知识与阅读

预测 y_hat=Xw，平方损失度量拟合误差。梯度下降与最小二乘应在小的满秩例子上得到一致结果。岭回归对参数加惩罚，截距是否惩罚必须写明。

[经典模型资源](../resources.md#ml)：回归章最小二乘与岭回归；回顾手册中的平方损失推导。

## 手算任务

对 x=[0,1,2]、y=[1,3,5] 写损失、梯度和最优参数；思考所有 x 相同时哪个参数不能唯一确定。

先独立完成，再看 [本周参考解](../answers.md#week-07)。参考解为自编，不是教师答案。

## 代码任务

运行 linear；遮住代码实现训练循环，画 loss 曲线，比较 lstsq。给预测加噪声，检查不再零残差。

在仓库根目录使用已准备好的 Python 环境执行：

```powershell
python 教材/scripts/examples.py linear
```

如使用 README 的虚拟环境，把 `python` 换成 `.venv/Scripts/python.exe`。安装范围和输出位置见 [环境准备](../setup.md)。跑通示例后遮住核心实现重写，不能只复制运行。
