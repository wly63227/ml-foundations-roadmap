# 第 03 周 · NumPy：形状、轴与绘图

## 问题与直觉

多列测量数据如何一次计算？数组让操作具有明确的形状，也让维度错误更容易被发现。

## 本周知识与阅读

X 的行是样本，列是特征。shape 描述各轴长度；axis=0 沿样本轴汇总。* 逐元素相乘，@ 表示矩阵乘法；切片可能共享内存，独立修改时先 copy。

[NumPy 入门范围](../resources.md#python)；先读创建数组、索引、形状和广播，不要求一次读完。

## 手算任务

X=[[1,2],[3,4],[5,6]]。求各列均值、X+[10,20]，以及 X@[1,-1]。

先独立完成，再看 [本周参考解](../answers.md#week-03)。参考解为自编，不是教师答案。

## 代码任务
