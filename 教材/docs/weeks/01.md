## 手算任务

手算读数 [1.0,1.2,0.8] 的均值及每个值相对均值的偏差。再给每个读数加 0.5，预测新均值。

先独立完成，再看 [本周参考解](../answers.md#week-01)。参考解为自编，不是教师答案。

## 代码任务

运行 basics；遮住示例后用循环重写求和，再用 sum 对照。加入条件，只统计大于等于 1 的读数。

在仓库根目录使用已准备好的 Python 环境执行：

```powershell
python 教材/scripts/examples.py basics
```

如使用 README 的虚拟环境，把 `python` 换成 `.venv/Scripts/python.exe`。安装范围和输出位置见 [环境准备](../setup.md)。跑通示例后遮住核心实现重写，不能只复制运行。
