## 问题与直觉

预测概率为什么不能直接用任意实数直线？把线性分数接到 sigmoid，再由似然得到损失。

## 本周知识与阅读

二分类标签为 0/1，p=sigmoid(Xw)。独立 Bernoulli 假设给出交叉熵。采用稳定 logaddexp 计算；L2 正则对非截距参数加惩罚，强度只用验证集选择。

[经典模型资源](../resources.md#ml)：线性分类的 logistic 小节；选读 D2L 的分类损失直觉。

## 手算任务

对单样本 x=(1,2)、w=(0,0)、y=1，求 p、交叉熵及对 w 的梯度（无正则）。

先独立完成，再看 [本周参考解](../answers.md#week-08)。参考解为自编，不是教师答案。

## 代码任务

运行 logistic；抄写推导后独立实现稳定损失及梯度，做有限差分。修改正则强度，观察权重而不是用训练准确率选最优。

在仓库根目录使用已准备好的 Python 环境执行：

```powershell
python 教材/scripts/examples.py logistic
```

如使用 README 的虚拟环境，把 `python` 换成 `.venv/Scripts/python.exe`。安装范围和输出位置见 [环境准备](../setup.md)。跑通示例后遮住核心实现重写，不能只复制运行。
