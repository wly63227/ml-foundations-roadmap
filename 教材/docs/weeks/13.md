## 问题与直觉

线性模型学不到的非线性关系，隐藏层能否表达？先观察验证曲线再增加模型规模。

## 本周知识与阅读

线性层叠加若无非线性仍是线性；ReLU 引入非线性。批大小影响更新频率；训练轮数、宽度和种子都要记录。网络更大不保证泛化更好。

[深度学习资源](../resources.md#dl)：D2L 4.1–4.4；先理解输入输出与过拟合。

## 代码任务

运行 neural（不加 --final）；用相同划分分别比较宽度 8 和 32，写入验证 MSE。保存训练与验证曲线，只在验证集选配置。

在仓库根目录使用已准备好的 Python 环境执行：

```powershell
python 教材/scripts/examples.py neural
```

如使用 README 的虚拟环境，把 `python` 换成 `.venv/Scripts/python.exe`。安装范围和输出位置见 [环境准备](../setup.md)。跑通示例后遮住核心实现重写，不能只复制运行。
