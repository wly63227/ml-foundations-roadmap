# 第 14 周 · CNN 直觉与训练稳定性

> 编者组织与自编练习 · 建议 9 小时 · 清单编号：D02、C01。学习状态：未开始。

## 问题与直觉

图像相邻位置存在结构，怎样用局部共享权重处理？本周先掌握形状与一个小卷积，不扩展到大架构。

## 本周知识与阅读

卷积有核、步幅、填充和通道。输出边长 floor((H+2p-k)/s)+1。权重衰减、dropout、学习率要逐项比较；eval 会影响 dropout。

[深度学习资源](../resources.md#dl)：D2L 4.5–4.6、6.2–6.3；不要求本周训练完整视觉系统。

## 手算任务

输入 (N,1,8,8)，Conv2d(1,4,kernel_size=3,padding=1,stride=1)，求输出形状和参数数。

先独立完成，再看 [本周参考解](../answers.md#week-14)。参考解为自编，不是教师答案。

## 代码任务

运行 neural 的卷积形状检查。固定其余配置，分别更改学习率与权重衰减，比较验证曲线；不要同时改多个参数。

在仓库根目录使用已准备好的 Python 环境执行：

```powershell
python 教材/scripts/examples.py neural
```

如使用 README 的虚拟环境，把 `python` 换成 `.venv/Scripts/python.exe`。安装范围和输出位置见 [环境准备](../setup.md)。跑通示例后遮住核心实现重写，不能只复制运行。
