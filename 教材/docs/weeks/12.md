> 编者组织与自编练习 · 建议 9 小时 · 清单编号：D01–D02、E02。学习状态：未开始。

## 问题与直觉

自动微分只是训练的一部分。数据、预测、损失、梯度与更新要按什么顺序连接？

## 本周知识与阅读

一轮训练包含前向、计算损失、zero_grad、backward、step。训练和验证用途不同；eval 不关闭梯度，no_grad 才停止记录。冻结参数与评估模式也不是同一件事。

[深度学习资源](../resources.md#dl)：D2L 3.2、4.7；可选 PyTorch Optimization。

## 手算任务

单样本 x=2,y=5，预测 wx+b，L=(wx+b-y)²/2，w=1,b=0。求两个梯度并用步长 0.1 更新。

先独立完成，再看 [本周参考解](../answers.md#week-12)。参考解为自编，不是教师答案。

## 代码任务

运行 autograd；独立写线性模型训练循环。删去一次 step 或 zero_grad，观察并解释错误现象，再恢复正确版本。

在仓库根目录使用已准备好的 Python 环境执行：

```powershell
python 教材/scripts/examples.py autograd
```

如使用 README 的虚拟环境，把 `python` 换成 `.venv/Scripts/python.exe`。安装范围和输出位置见 [环境准备](../setup.md)。跑通示例后遮住核心实现重写，不能只复制运行。
