## 问题与直觉

读数存进文件后，怎样稳定地重新计算？把重复步骤封装为函数，比复制很多行更容易排错。

## 本周知识与阅读

函数的参数是输入，return 是输出；文件路径相对当前工作目录。CSV 表头不是数值。空数据不能求平均；捕获异常前先读懂原因。列表查找与遍历先理解 O(n)。

[环境准备](../setup.md)；Python 教程的函数、输入输出、异常部分，见 [资源](../resources.md#python)。

## 手算任务

读数 1.0、1.2、0.8，相对标称值 1.0 的平方误差均值是多少？遍历 n 个读数与两两比较大约各执行多少次？

先独立完成，再看 [本周参考解](../answers.md#week-02)。参考解为自编，不是教师答案。

## 代码任务

运行 basics，查看生成的 CSV。独立写 mean(values)，空列表时 raise ValueError；读取 CSV 后调用函数。用 git status/diff 检查，再暂存自己的练习并提交。

在仓库根目录使用已准备好的 Python 环境执行：

```powershell
python 教材/scripts/examples.py basics
```

如使用 README 的虚拟环境，把 `python` 换成 `.venv/Scripts/python.exe`。安装范围和输出位置见 [环境准备](../setup.md)。跑通示例后遮住核心实现重写，不能只复制运行。
